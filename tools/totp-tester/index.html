HOW IT WORKS

Test a time-based one-time password

TOTP is a standard for generating short-lived verification codes from a shared secret and the current time. This free online TOTP tester calculates codes in your browser using the selected algorithm, code length and refresh period. Compare the displayed code with your authenticator setup, and check that your device clock is accurate if a code is rejected.

Are my authenticator secrets uploaded?

No. Code generation, local autosave, and backup encryption run in your browser. This page does not send your secret or generated codes to a server. Your browser's local storage is readable by anyone with access to the same browser profile, so use a trusted device.

How do backup and restore work?

The downloaded backup is encrypted with AES-256-GCM using a key derived from your passphrase. Restore decrypts the file in this browser and merges its accounts with local accounts. A lost passphrase cannot be reset.

Why might a generated code not work?

Check that the secret is entered correctly, the selected algorithm, code length and period match the service, and your device time is synchronized automatically. Most services use SHA-1, six digits and a 30-second period.
