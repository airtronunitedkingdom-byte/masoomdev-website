How to install on Chrome

  1. Download the ZIP file and extract it to a permanent folder.
  2. Open chrome://extensions.
  3. Enable Developer mode and select Load unpacked.
  4. Choose the folder containing manifest.json.

Review requested extension permissions before installation. Downloads are hosted on GitHub Releases, not the Chrome Web Store.
