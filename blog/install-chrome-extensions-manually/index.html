How to Install a Chrome Extension from a ZIP File

Use Developer Mode carefully when installing unpacked extensions.

What you need to know

Download the extension from a trusted source and inspect its contents before installation.

Extract the ZIP into a permanent folder; Chrome loads the unpacked extension from that folder.

Open chrome://extensions, enable Developer mode and select Load unpacked, then choose the folder containing manifest.json.

Review requested permissions and test the extension on a non-sensitive page first.

Updates are not automatic for many unpacked extensions, so check the source for fixes and security updates.

Quick checklist

  • Identify your goal and the required output.
  • Keep an original copy before making changes.
  • Verify the result on the device or service where it will be used.
