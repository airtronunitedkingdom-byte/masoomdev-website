Masoom Macro Recorder — Privacy Policy

Effective 7 November 2026

What the app records

When you enable recording, the app may capture keyboard input, mouse movements, clicks, scrolling and timing. These records can include sensitive information typed during a session.

Storage

Recorded events are kept in application memory while in use. When you choose Save, a JSON macro file is written to the location you select on your computer. Error diagnostics may be saved under Windows LocalAppData.

Network and data collection

The current app source does not implement a user account, cloud synchronization, analytics SDK or upload of recorded events to MasoomDev servers. Windows, Microsoft .NET and other software may process information independently.

Your controls

You decide when to start and stop recording, which input categories to enable, and whether to save or delete local files. Review recordings before sharing them. Avoid recording passwords, financial information or confidential content.

Changes and support

This policy may change as the application evolves. For questions, visit MasoomDev Support or the GitHub issue tracker.
