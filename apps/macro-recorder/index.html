Masoom Macro Recorder

Record mouse movements, clicks, scrolling and keyboard actions, then replay sequences with repeat and speed controls. Save and load macros as local JSON files.

Download latest Windows releaseSource & updates

Latest release verified when this page was prepared: v1.0.5. Windows x64; lightweight builds require the Microsoft .NET 8 Desktop Runtime (x64). See the release page for current versions.

Features

  • Mouse movement, clicks and scroll recording
  • Keyboard recording with F8 stop and F9 playback pause/resume
  • Repeat count, timed playback and adjustable playback speed
  • Local JSON save/load and event editing
  • Windows installer and portable ZIP available through GitHub Releases

Privacy reminder: Recording may capture sensitive keystrokes. Do not record passwords or private data.
